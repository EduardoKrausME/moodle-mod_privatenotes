# Changelog

This changelog documents only the two most recent published GitHub releases. Each entry is based on the differences between its release tag and the immediately preceding published release. Changes made later on `master` are excluded.

- Added the plugin icon image at `pix/icon.png` and reorganized the SVG logo asset as `pix/monologo.svg`.
- Updated the plugin release identifier from `1.1.6` to `1.1.7` and its build number from `2026101500` to `2026101501`.

No functional changes to the private-notes activity were identified between the published `1.1.6` and `1.1.7` releases.
